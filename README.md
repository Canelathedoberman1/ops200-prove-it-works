Prove It Works

A mini Mortgage Calculator project built with React and tested with automated unit and end-to-end tests.

Features
Mortgage payment calculator
Calculator utility functions
Unit tests using Mocha and Chai
End-to-end tests using Playwright
Webpack build configuration
Express server for serving the application
Installation

Install the project dependencies:

npm install
Run the Application

Build the application:

npm run build

Start the Express server:

npm start
Run Tests

Run all unit and end-to-end tests:

npm test

The project contains:

12 unit tests
10 end-to-end tests
22 total automated tests

All tests should pass before submitting the project.

Submit

The submit script runs the complete test suite:

npm run submit
